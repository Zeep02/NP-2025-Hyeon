# UDP Echo

## 프로토콜 요약
| 구분 | 내용 |
| --- | --- |
| 요청 | 클라이언트가 `sendto(payload, ("localhost", 2500))`로 메시지 송신. |
| 응답 (정상) | 서버가 동일한 데이터 또는 가공 데이터(`udp_oop`에서 길이 정보)를 `sendto`로 회신. |
| 응답 (예외) | 서버가 응답하지 않으면 클라이언트 `recvfrom`이 블록; 필요 시 타임아웃 설정으로 예외 처리 가능. |
| 오류 조건 | 포트 미바인딩/방화벽/잘못된 주소로 인한 `OSError`; UDP는 전송 보장 없으므로 패킷 손실 시 재전송 필요. |
