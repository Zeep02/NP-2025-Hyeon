# UDP 연습문제 프로토콜

## 객체지향 확장 (연습문제 4)
| 구분 | 내용 |
| --- | --- |
| 요청 | `udp_oop.py` 실행 시 `python ... s`는 서버, `python ... c`는 클라이언트. 클라이언트가 현재 시각 문자열을 UDP로 전송. |
| 응답 (정상) | 서버가 수신 길이 정보를 문자열로 만들어 `sendto`. |
| 응답 (예외) | 서버가 응답하지 않으면 클라이언트 `recvfrom`이 블록; 타임아웃 미설정이라 계속 대기. |
| 오류 조건 | 포트 이미 사용 중일 때 서버 `bind` 실패, 잘못된 호스트 지정 시 `OSError`. |
