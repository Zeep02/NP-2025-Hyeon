# 멀티캐스트 연습문제 프로토콜

## 연습문제 7 (이기종 환경 실행)
| 구분 | 내용 |
| --- | --- |
| 요청 | Windows에서 `multicast_recv.py` 실행(서버), Ubuntu 등에서 `multicast_send.py` 실행(클라이언트). 각 클라이언트는 메시지 입력 후 멀티캐스트 전송. |
| 응답 (정상) | 서버가 모든 메시지를 출력하고 `ACK`를 각 클라이언트로 `sendto`. |
| 응답 (예외) | 송신 측 타임아웃 발생 시 `timeout` 예외로 ACK 대기 종료. |
| 오류 조건 | 그룹 가입 실패(`IP_ADD_MEMBERSHIP`), TTL 설정 오류, 네트워크 멀티캐스트 차단 등. |
