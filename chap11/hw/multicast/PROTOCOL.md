# UDP 멀티캐스트

## 프로토콜 요약
| 구분 | 내용 |
| --- | --- |
| 요청 | 송신자가 멀티캐스트 그룹 주소(`224.0.0.255:5005`)로 `sendto` 수행. |
| 응답 (정상) | 가입된 각 수신자가 메시지를 출력 후 `ACK`를 송신자에게 개별 전송. 송신자는 ACK를 타임아웃 내 수신. |
| 응답 (예외) | 타임아웃(0.5초) 동안 ACK 미수신 시 `timeout` 예외 발생 → 루프 종료 후 다음 메시지 입력. |
| 오류 조건 | 수신자가 그룹 가입(`IP_ADD_MEMBERSHIP`) 실패 시 `OSError`. TTL이 0이면 로컬 링크를 벗어나지 못함. |
