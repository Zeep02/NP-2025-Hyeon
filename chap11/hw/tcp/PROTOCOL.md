# TCP Time 서버/클라이언트

## 프로토콜 요약
| 구분 | 내용 |
| --- | --- |
| 요청 | 클라이언트가 `connect(("localhost", 5000))` 호출 후 `recv()` 대기. |
| 응답 (정상) | 서버가 `time.ctime()` 결과를 `send()`로 전송, 클라이언트는 디코드 후 출력. |
| 응답 (예외) | 서버가 중간에 `close` 하거나 송신 실패 시 `recv()`가 빈 바이트 반환 → 클라이언트 루프 종료. |
| 오류 조건 | 서버 미기동/포트 불일치 → `ConnectionRefusedError`. 포트 충돌 → 서버 `bind` 단계에서 `OSError`. |
