# UDP 브로드캐스트

## 프로토콜 요약
| 구분 | 내용 |
| --- | --- |
| 요청 | 송신자가 `sendto(msg, ("<broadcast>", 10000))` 호출. |
| 응답 (정상) | 브로드캐스트 특성상 명시적 응답 없음. 각 수신 호스트는 `recvfrom` 후 콘솔 출력. |
| 응답 (예외) | 응답 자체가 없으므로 타임아웃 처리 없음. 필요 시 응답용 별도 포트를 설계해야 함. |
| 오류 조건 | `SO_BROADCAST` 미설정 → `PermissionError`. 네트워크에서 브로드캐스트 차단 시 패킷 미도달. |
